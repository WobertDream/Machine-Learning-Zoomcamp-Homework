# Machine Learning Zoomcamp - Homework
This repository contains my code for assignments and projects for the **Machine Learning ZoomCamp 2026** course by **[DataTalks](https://github.com/DataTalksClub/machine-learning-zoomcamp/tree/main)**
## Structure
This repository is organised by week/module

* **`01-intro/`** - Homework 1: Introduction to Machine Learning
* **`02-regression/`** - Homework 2: Machine Learning for Regression
* **`03-classification`** - Homework 3: Machine Learning for Classification

## Module Contents

### Module 1: Introduction to Machine Learning
* **Topics Covered:**
  * Introduction to Numpy
  * Introduction to Pandas
  * Linear Algebra Basics
  * Machine Learning concepts (supervised learning, model selection, crisp-dm etc)

### Module 2: Machine Learning for Regression
* **Topics Covered:**
  * Linear Regression (simple, vector, training)
  * Feature Engineering
  * Regularisation
  * Model Tuning
  * Validation Framework

### Module 3: Machine Learning for Classification
* **Topics Covered:**
  * Logistic Regression (training, intepretation)
  * One-hot encoding
  * Mutual Information and Risk Ratio
  * Correlation
